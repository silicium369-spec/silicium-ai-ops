# Security Policy

## Supported Versions

Only official evaluation packages and native shared libraries (`libsilicium_ann_x86_64.so`) matching the published SHA-256 cryptographic digest in `checksums.sha256` are supported.

## Reporting a Vulnerability

If you discover a memory safety issue, C-ABI boundary vulnerability, or potential security flaw in Silicium-ANN, please report it via GitHub Security Advisories on the official `silicium369-spec` repository rather than opening a public issue.
